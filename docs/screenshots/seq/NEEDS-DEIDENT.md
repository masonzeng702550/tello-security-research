# ⚠️ 本目錄的截圖含個人環境影像，發布前必須去識別化

`t01.png` – `t20.png` 為 2026-08-18 連機測試期間每 15–20 秒自動擷取的畫面序列。

## 問題

自 `t13.png` 起，Tello 影像串流已連通，畫面中包含：

- 拍攝者的**居家環境**（地板、家具、門窗）
- **人體部位**（腳）
- **筆電螢幕內容**（可能含檔案路徑、程式碼、視窗標題）

## 發布前處理

- [ ] 逐張檢視，將影像串流區域**遮蔽或裁切**
- [ ] 筆電螢幕區域**必須**遮蔽，不可只靠縮圖模糊
- [ ] 保留 UI 疊層（警告列、控制項、狀態列）—— 那才是研究要展示的部分
- [ ] 確認狀態列不含可識別資訊

## 可安全發布的部分

畫面**上方狀態列**與**下方警告列**是研究重點所在
（`ERROR CODE：29`、`飛控傳感器異常`、電量、高度、速度），
這些區域不含個人資訊，裁切後可直接使用。

> 依 `03-ethics-legal.md`，本專案的公開素材不得包含可識別個人或住所的影像。
